# 🎂 JingJing 的生日街机 · HAPPY BIRTHDAY

一个打开就能玩的生日网页：8-bit 街机外壳 + 接礼物的像素小游戏 + JingJing 的生日档案。
纯静态、零依赖、断网也能跑，手机和电脑都适配。

---

## 本地查看

直接双击 `index.html` 打开即可。

---

## 页面里有什么

- **街机小游戏**：← → 或 A / D 移动底部小人（手机点屏幕上的 ◀ ▶），接住蛋糕、礼物、星星得分。
- **生日档案**：名字、生日（农历八月初七）、本命年徽章、LEVEL 与倒计时。
- **闯关时间轴**：把她的这些年做成街机关卡表。
- **像素猫四月**：和祝词一起出现的 12×12 像素布偶猫。
- **右下角**：生日歌与音效开关，浏览器实时合成。
- 心掉光了也不会 GAME OVER，会有人跑进来给你补满血接着打。

---

## 文件结构

```
birthday4jing/
├── index.html          # 全部内容：街机外壳 + 游戏 + 生日档案 + 祝词
├── assets/common.js    # 共享交互库：音效 / 生日歌 / 五彩纸屑 / 打字机 / 滚动出现
└── README.md
```

页面用到的音效、生日歌、纸屑都由 `assets/common.js` 现场合成，没有图片和音频文件。
